# Кварта

[Сайт](https://kvarta-five.vercel.app/) · [Переписка с ИИ](docs/Копипаст%20чатов/README.md) · [Lighthouse](docs/lighthouse/)

Лендинг вымышленной обжарки на Next.js, TypeScript и Tailwind. Форма отправляет заявку в `POST /api/lead`: проверяет белорусский телефон, сообщает об ошибках, сохраняет UTM и страницу входа. PostgreSQL на Neon выбран для постоянного хранения на Vercel и транзакционной защиты от повторов одного номера в течение 10 минут, включая параллельные запросы.

**Моя работа.** Разбирал бриф с ИИ, выбирал визуальную концепцию, принимал результат и согласовывал тексты. Настроил Neon и Vercel с подсказками, добавил секреты вне Git, проверил успешную и повторную отправку в браузере, снял Lighthouse и сохранил переписку. Самостоятельную реализацию кода себе не приписываю.

**Работа ИИ и ошибки.** Cursor реализовал страницу, API и проверки. ChatGPT помогал с планом, изображением, редактурой и разбором переданного кода; финально проверил и сократил документацию через GitHub. Я запросил дополнительный разбор: он выявил, что первоначальные тесты дублировали реализацию, тестовый номер был неверной длины, а ошибка подключения обрабатывалась не полностью. Cursor исправил код и тесты. Маленький размытый кадр заменили отдельным сгенерированным изображением. В редактуре участвовала подруга-филолог; итоговые формулировки утверждал я.

**Проверки и ограничения.** Ранее прошли lint, TypeScript, build, проверки API и адаптива 360/1440 px. Lighthouse: 70 и 73 / 100 / 100 / 100, до финальной редактуры; DevTools mobile, Slow 4G, CPU ×4, экранная эмуляция отключена, ширина полного снимка 412 px. Производительность требует улучшения: следующим шагом разобрал бы длительные задачи главного потока и повторил замер с явно включённой эмуляцией. Дублирование в Telegram не реализовано. Контакты, которых нет в брифе, не выдумывались; упаковка на фото нейтральная.

Запуск: `npm install` → создать `.env.local` по `.env.example` с `DATABASE_URL` → `npm run db:migrate` → `npm run dev`. Секреты не коммитить.
