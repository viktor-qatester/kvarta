# Инструкция повторения пройденных этапов

Это восстановленная инструкция, а не дословный лог диалогов. Основной журнал — `ai-log.md`.

Секреты, полные строки подключения и персональные данные сюда не входят.

Инструкция описывает только то, что уже сделано и подтверждено журналом, историей Git или сообщением Виктора. Где точная команда в этих источниках не записана, это прямо отмечено. Такие места нельзя додумывать и запускать «по памяти».

Для каждого шага: где действовать, что сделать, какой результат ожидался, как это проверяли.

`npm start` запускает уже собранный production-сервер. После изменений в коде он показывает старую сборку, пока снова не выполнены `npm run build` и запуск. Во время разработки смотрят dev-сервер: `npm run dev`, он подхватывает правки без отдельной сборки. В журнале проверки страниц записаны через `npm run build` и затем `npm start` на http://localhost:3000. Запуск `npm run dev` в журнале не записан.

## Уроки

Из сравнения эскизов и приёмки вида:

- Изображения макетов могут содержать выдуманные факты. На эскизах Gemini были чужие телефоны, часы, цены и искажённые тексты.
- Картинка макета не заменяет интерфейс. Сайт собирали отдельно, страница длиннее эскиза: текст 16 px, зоны нажатия от 44 px.
- Маленький вырезанный кадр недостаточен для крупного изображения. `hero-kitchen.jpg` получен из эскиза и имеет размер 338×304. Замена на качественное изображение отложена.
- Успешная сборка показывает, что проект собирается. Отправка формы при этом оставалась выключенной.
- `SELECT 1` подтверждает соединение с Neon. Сохранение заявок этим запросом не проверяется: таблиц и API нет.

Другие подтверждённые сбои из `ai-log.md`:

- При осмотре создали `ai-log.md`, хотя в том запросе файлы ещё просили не создавать. Запись не переписывали.
- Поиск брифа по всей домашней папке упёрся в отказ доступа Windows. Файл нашёлся после сужения до Documents, Desktop и Downloads.
- Первая установка зависимостей заняла около 8 минут. `eslint@9.39.5` помечен как deprecated. Postinstall `unrs-resolver@1.12.2` не покрыт `allowScripts`; линт после этого прошёл.
- `npm audit` показал 5 high в цепочке dev-зависимостей `braces` → `micromatch` → `fast-glob` → `@next/eslint-plugin-next` → `eslint-config-next`. `npm audit fix --force` не запускали: он поставил бы `eslint-config-next@14.2.35`. Для production-зависимостей отчёт был 0.
- Первый снимок стартовой страницы был чёрным: прозрачный фон и чёрный текст. После `bg-white` текст стал виден. Один вызов снимка вернул «Screenshot capture failed - no image data returned from main process».
- Шаблон `app-tw-empty` включил в `next.config.ts` `cacheComponents` и `partialPrefetching`. Настройки оставили как сгенерированные, сборка прошла.
- До первого коммита `git log` сообщил, что у `main` ещё нет коммитов.
- Кнопка героя на десктопе растянулась на всю колонку из-за `flex-col` и `align-items: stretch`. Исправление: `sm:self-start` и `sm:w-auto`.
- Клик инструмента браузера по товару перехватывала липкая шапка. Выбор проверили событием `click` в DOM. Программный `button.click()` меню не открыл; открытие, Escape и переход проверили обычным кликом инструмента.
