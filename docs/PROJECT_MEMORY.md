## Данные

Размещение выбрано: Vercel + Neon Postgres. Vercel ещё не подключался.

Neon: проект `kvarta`, регион Frankfurt, план Free. Аккаунт создавал Виктор.

`DATABASE_URL` хранится в `.env.local` рядом с `package.json`. Файл игнорируется правилом `.env*`. Шаблон без секрета: `.env.example` со строкой `DATABASE_URL=`. Для базы не используется `NEXT_PUBLIC_`.

Установлен `@neondatabase/serverless` 1.2.0 (`^1.2.0` в `package.json`). Cursor выполнил `SELECT 1 AS ok` и получил `ok`, равный 1. Таблиц и API нет. Обычная транзакция для защиты от параллельных дублей заранее признана недостаточной; механизм ещё не выбран.
