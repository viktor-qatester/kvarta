# Правила работы над «Квартой»

- Перед изменением требований читать `docs/kvarta-brief.pdf`.
- Работать небольшими проверяемыми этапами.
- Вести `ai-log.md` по фактам. Не выдумывать проверки и ошибки.
- Не добавлять вымышленные контакты, отзывы и факты о клиенте.
- Секреты хранить в переменных окружения и не коммитить.
- Изменения вносит один агент за раз.
- Push, merge и деплой — только по явной команде заказчика.
